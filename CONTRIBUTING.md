# Contributing to FitStride

Thank you for your interest in contributing to the FitStride Running App!

## Development Workflow

1.  Ensure you have read and understood the development rules outlined in `../rules.md`.
2.  Create a new branch from the `develop` branch for your feature or bug fix (e.g., `feature/new-tracking-metric` or `fix/login-bug`).
3.  Make your changes, adhering to Flutter best practices and the project's coding style.
4.  Write unit tests for any new logic introduced.
5.  Ensure all tests pass (`flutter test`).
6.  Update the `../tasks.md` checklist if your changes address specific tasks.
7.  Commit your changes with clear and descriptive messages.
8.  Push your branch to the repository.
9.  Create a Pull Request against the `develop` branch.

## Coding Style

*   Follow the official [Effective Dart](https://dart.dev/effective-dart) guidelines.
*   Use static typing and provide type annotations.
*   Keep lines under 100 characters.
*   Add comments to explain complex logic.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on the project's issue tracker (if applicable). Provide as much detail as possible.

## Code of Conduct

Please note that this project adheres to a Code of Conduct. Be respectful and considerate in all interactions.
